# NeonStream - Live Streaming Platform

Een moderne streaming website met neon design, live chat, gifts, opnames en meer.

## Features

- Live streaming (camera of scherm delen)
- Opname starten/stoppen en downloaden
- Live chat met emoji's
- Gift systeem met animaties
- Kijkers lijst
- Statistieken dashboard
- Volledig responsive design

## Hosting

### GitHub Pages
1. Push deze repo naar GitHub
2. Ga naar Settings > Pages
3. Selecteer "main" branch en klik Save
4. Je site is live op `https://jouwgebruikersnaam.github.io/stream-platform/`

### Netlify
1. Ga naar [netlify.com](https://netlify.com)
2. Sleep de project map naar de upload zone
3. Klaar!

## Gebruik

- **Go Live** - Start je camera stream
- **Scherm** - Deel je scherm
- **Opname** - Neem je stream op
- **Chat** - Verstuur berichten met emoji's
- **Gifts** - Stuur animatie gifts
- **Dubbelklik titel** - Wijzig stream titel
